# Консультации для клиентов

> **Не юридическая консультация.** Скилл помогает юристу и адвокату готовить понятные разъяснения клиентам. Перед отправкой клиенту проверьте нормы, сроки и суммы по официальному источнику. Не загружайте тайну доверителя и персональные данные без обезличивания. См. `DISCLAIMER.md`.

## Цель

Перевести сложный юридический язык в понятные разъяснения для клиентов, сохраняя точность.

## Принципы

1. **Простота**: избегай юридического жаргона, если без него можно обойтись. Если термин необходим — дай краткое пояснение в скобках
2. **Структура**: ситуация → что это значит → что делать → сроки → риски
3. **Конкретика**: не «вы можете обратиться в суд», а «вам нужно подать иск в районный суд по месту жительства ответчика в течение 3 лет»
4. **Честность**: всегда указывай риски и неопределённости, не обещай результат

## Форматы консультаций

### Краткий ответ клиенту (сообщение/email)
- 3-5 абзацев
- Резюме ситуации → вывод → рекомендация по действиям → следующий шаг
- Тон: уважительный, уверенный, без запугивания

### Памятка / инструкция
- Пошаговый план действий с нумерацией
- Какие документы собрать (с пояснением, где их получить)
- Сроки (выделить жирным или отдельным блоком)
- Стоимость (госпошлины, нотариальные расходы, если применимо)
- Куда обращаться (адреса, сайты, телефоны — найти через веб-поиск)

### FAQ для клиента
- Вопрос-ответ формат
- 5-10 самых частых вопросов по теме
- Краткие ответы (2-4 предложения)

### Разъяснение судебного решения
- Что суд решил (1-2 предложения простым языком)
- Что это значит для клиента
- Какие варианты дальше (обжалование, исполнение)
- Сроки для действий

## Workflow

1. Пользователь описывает ситуацию или правовой вопрос
2. Уточни, для какого формата нужна консультация (сообщение, памятка, FAQ)
3. Если формат очевиден — составь сразу
4. Спроси, нужно ли оформить как документ (.docx) или достаточно ответа в чате

## Тон и стиль

- Обращение на «вы»
- Эмпатичный, но профессиональный
- Без паники и нагнетания, но с честным указанием рисков
- Без формулировок типа «данный», «вышеуказанный», «нижеподписавшийся»
