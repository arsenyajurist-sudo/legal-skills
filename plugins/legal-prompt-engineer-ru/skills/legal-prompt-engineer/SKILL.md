# Юрист-промпт-инженер

> **Не юридическая консультация.** Скилл пишет промпты для ИИ, а не заключения. Ответы ИИ могут быть ошибочными: проверяйте каждую норму и практику по первоисточнику. Не вставляйте в промпты тайну доверителя и персональные данные без обезличивания. См. `DISCLAIMER.md`.

Навык превращает короткую просьбу юриста в развёрнутый, профессиональный промпт для ИИ —
такой, чтобы нейросеть выдала максимально полезный черновик с первого раза, не «лила воду»
и не выдумывала нормы и практику.

## Главный принцип

Слабый промпт = «проверь договор». Сильный промпт задаёт нейросети **роль, контекст, материалы,
точную задачу, способ рассуждения, ограничения, формат вывода и самопроверку**. Чем точнее рамка —
тем сильнее результат. Для современных моделей трюки вроде
«ты эксперт с 20-летним стажем, я заплачу 100$» не нужны — нужна чёткая структура.

## Скелет сильного юридического промпта (8 блоков)

Каждый мега-промпт собирается по этому каркасу. Блоки 1–5 обязательны, 6–8 — почти всегда.

1. **РОЛЬ** — кто нейросеть и чьи интересы защищает.
   «Ты — юрист по [отрасль], защищаешь интересы [сторона].»
2. **КОНТЕКСТ** — суть ситуации простыми словами: кто, с кем, о чём, что произошло, стадия.
3. **МАТЕРИАЛЫ** — что юрист вставит: «Договор/материалы дела/судебный акт: [вставить целиком]».
   Прямо проси вставлять документы целиком — у моделей большое окно памяти.
4. **ЗАДАЧА** — что именно сделать, по пунктам. Глаголами: проверь, найди, составь, сравни, оцени.
5. **КАК ДУМАТЬ** — способ рассуждения: «продумай шаг за шагом», «рассмотри слабые места моей
   позиции и контраргументы оппонента», «сначала дай план, потом выполни».
6. **ОГРАНИЧЕНИЯ И СТОП-ПРАВИЛА** — главное для юриста:
   - «Не выдумывай номера дел, статьи и реквизиты. Если не уверен — пометь [ПРОВЕРИТЬ].»
   - «Опирайся только на факты из моих вводных, не додумывай обстоятельства.»
   - «Ссылайся на действующую редакцию норм; если редакция могла измениться — предупреди.»
7. **ФОРМАТ ВЫВОДА** — вид результата: таблица «пункт → риск → как переформулировать»,
   структура документа, объём, тон. Для документов — задавай процессуальную структуру (см. ниже).
8. **САМОПРОВЕРКА** — «перепроверь ответ, отметь, где можешь ошибаться и что требует проверки
   по первоисточнику».

## Процессуальные структуры (вшивать в блок ФОРМАТ)

- **Исковое заявление** (ГПК ст. 131–132): суд → истец → ответчик → цена иска → обстоятельства →
  правовое обоснование (нормы) → «ПРОШУ» → приложения → дата/подпись.
- **Претензия**: кому → от кого → обстоятельства → правовое обоснование → требование + срок →
  предупреждение о суде → приложения.
- **Апелляционная/кассационная жалоба**: вышестоящий суд → заявитель → обжалуемое решение →
  доводы (нарушения норм материального/процессуального права) → просительная часть → приложения.
- **Ходатайство**: суд, № дела → стороны → наименование → обоснование (факт + право) → просьба.

## Правила тона и качества

- Промпт пишется на «вы»/нейтрально, без воды, готов к копипасту.
- Все переменные — в `[квадратных скобках]`, чтобы юрист быстро подставил своё.
- Длина: сильный промпт — это 8–20 строк. Не бойся «больших» промптов — они работают лучше.
- В конце сложных промптов всегда — стоп-правило про выдуманную практику и дисклеймер
  «решение и подпись — за юристом».
- Никаких гарантий результата, никакой замены юриста — ИИ готовит черновик, оценивает юрист.

## Что навык НЕ делает
- Не составляет сам готовый документ (это legal-docs).
- Не даёт юридическую консультацию по существу дела.
- Не выдумывает нормы и практику — и прямо запрещает это нейросети в каждом промпте.

## Формула на одну строку (быстрый режим)
Если нужен короткий промпт: **РОЛЬ + КОНТЕКСТ + МАТЕРИАЛЫ + ЗАДАЧА + ФОРМАТ + «не выдумывай, помечай [ПРОВЕРИТЬ]»**.
